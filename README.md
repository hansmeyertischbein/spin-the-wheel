# Snurr hjulet

Premiehjul med 15 like store felt. Trekningen er vektet, og sannsynlighetene står på plakaten ved standen:

| Premie | Sannsynlighet |
| --- | --- |
| Kaffemaskin | 0,0001 % |
| JBL lydplanke | 0,0001 % |
| Liten JBL | 1 % |
| Paraply | 1 % |
| Red Bull | 24,49995 % |
| Klesrulle | 24,49995 % |
| Tannbørste | 24,49995 % |
| Ski- og stavholder | 24,49995 % |

Åpne siden, trykk på hjulet eller mellomromstasten for å snurre. Esc lukker resultatet.

Oddsene endres øverst i `wheel.js`.
